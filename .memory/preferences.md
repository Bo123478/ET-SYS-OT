# Preferences

- [docs-and-code-style] 文档语言中文。记忆写法 = Hemingway 风：短句、无术语、无填充、直白。文档版本号写在文件头（方案/进度/待办都有版本号 + 更新日期）。进度用状态图例 ✅🟡⬜⏸❌➖。待办五类前缀 B/T/D/G/M + P0/P1/P2 优先级，标 BLOCK 的未决前别动代码。

- [vscode-ai-et-databricks-powerbi-goal] 用户希望以 VS Code + AI 辅助开发 ETWorkbench 采集落目录 → Databricks 清洗存储 → Power BI 展示；当前是方案讨论，不代表授权启用暂缓的平台侧或部署云资源。

- [end-to-end-before-features] 用户要求先打通 ETWorkbench→数据搬运→Databricks→Power BI 的全链路，再开展具体功能开发；优先最小端到端验证，勿让 MCP 配置阻塞数据链路。
